# worldview worker prompt

这个文件是 Stage 2 世界观文档 worker agent 的执行模板。Main thread 只传摘要缓存路径和输出路径,不要传摘要正文。

## 输入

你会收到一个任务对象或等价文字,至少包含:

- `slug`: 小说标识
- `title`: 输出标题,如 `《sample》世界观`
- `input_path`: `library/{slug}/_cache/all_summaries.md` 或长篇模式下的 `_cache/all_arc_summaries.md`
- `output_path`: `library/{slug}/世界观.md`

## 任务

读取 `input_path` 中按顺序排列的块摘要缓存或分段摘要缓存,整理小说实际出现的世界观设定,并直接写入 `output_path`。不要把完整文档回传给 main thread。

## 应涵盖

只写摘要里实际出现的内容,缺什么就略过:

1. 时空背景:朝代/年代/星球/位面
2. 核心规则:力量体系、修炼体系、魔法/科技规则、特殊机制
3. 重要组织/势力:名字、立场、相互关系
4. 特殊设定:金手指、系统、神器、特殊职业、特殊物品
5. 种族/物种
6. 地理/重要地点
7. 涉及性 / 双修 / 特殊伦理体系等设定时(如修炼需采阴补阳、社会合法化乱伦、性力量等),如实记录,中性陈述

## 不要写

- 摘要里没有直接支持的设定
- 普通现实常识,除非小说赋予新设定
- 具体剧情展开,那属于故事线

## 纯现实题材处理

如果小说没有超自然、异世界、特殊科技或力量体系,不要硬凑。简短说明现实题材背景,再列出行业、地点、组织、人物关系等值得记的背景元素。

## 风格和引用

- 1200-2500 字
- 第一行必须是 `# {title}`
- 用 `##` 二级标题分组
- 列表和段落混用
- 每条具体设定后加块号 `[块 N]` 或 `[块 N, M]`
- 中性陈述,不评价

## 写入要求

- 使用 UTF-8 写入 `output_path`
- markdown 正文中不要出现 JSON 围栏或任务说明
- 写完后不要在回复里粘贴正文

## 最终回复

只回复一行短状态:

- 成功: `OK doc=世界观`
- 失败: `FAILED doc=世界观 reason=简短原因`
